## 📝 Customization Guide

### Update Personal Info
Search and replace in `index.html`:
- `your.email@example.com` → Your email
- `linkedin.com/in/yourprofile` → Your LinkedIn
- `github.com/yourusername` → Your GitHub

### Modify Colors
Edit CSS variables in the `:root` selector:
```css
:root {
    --primary: #00ff88;      /* Main accent color */
    --secondary: #00d4ff;    /* Secondary accent */
    --accent: #ff0080;       /* Tertiary accent */
    --bg-dark: #0a0e1a;      /* Background */
}
```

### Add Projects
Duplicate a `.project-card` div and update:
- Project icon
- Title
- Description
- Technology tags
- Links
