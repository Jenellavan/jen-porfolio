# Assets Directory

Place your custom logo file here.

## Supported Formats
- PNG (logo.png)
- SVG (logo.svg)
- WebP (logo.webp)

## Recommended Specifications
- Size: 200x200px (will be scaled automatically)
- Background: Transparent
- Colors: Navy (#003057) and/or Gold (#D4AF37)
- Style: Professional, clean, banking-appropriate

## How to Use Your Logo

1. Place your logo file in this directory
2. Open `frontend/src/components/Logo.js`
3. Follow the instructions in the comments to import and use your logo
4. The logo will automatically appear in the navbar

Example:
```jsx
import logoImage from '../assets/logo.png';
```
